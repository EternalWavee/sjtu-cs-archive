## 作业内容

| Lab | 主题 |
|-----|------|
| Lab01 | **Algorithm Analysis** — Scaled Dot-Product Attention / Multi-Head Attention 复杂度分析 |
| Lab02 | **Greedy Algorithm** — 分数背包、最小区间覆盖，贪心正确性证明（Exchange Argument） |
| Lab03 | **Dynamic Programming** — 动态规划建模与求解 |
| Lab04 | **Amortized & Graph** — 平摊分析、图算法 |
| Lab05 | **TM & Complexity** — 图灵机设计、P/NP 复杂性 |
| Lab06 | **Approximation** — 近似算法分析 |
